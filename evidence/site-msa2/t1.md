# t1 — web-server API とモックデータ

`web-server/server.py` に標準ライブラリだけで動く HTTP origin を実装した。静的配信、`/healthz`、会議一覧・詳細、テンプレートの取得／PUT、publish 受け口、音声配信を含む。データは `data/` を `PLAUDE_DATA_DIR` で切替可能にし、`mock-safety` のメタデータ・要約・タイムスタンプ付き文字起こし・短い MP3 fixture を同梱した。

## 検証

`python3 -u web-server/test_server.py` を隔離 worktree で実行し、成功した。

- `/healthz`、会議一覧、会議詳細、テンプレート一覧・PUT・再取得、publish を localhost の実サーバー経由で検証した。
- `mock-safety` 詳細の `has_audio` が `true` であること、`GET /m/mock-safety/audio` が空でない `audio/mpeg` を返すことを検証した。
- テスト用のテンプレートと publish 会議データは終了時に削除されることを確認した。

結果: `origin probes ok 08-18 安全教育: 第85期 お盆明け立ち上がり安全教育`
