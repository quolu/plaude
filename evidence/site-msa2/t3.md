# t3 — テンプレ CRUD とコミュニティ投入

## 実装

- 既存の6テンプレートをそのまま残した。
- `templates/` に24件を追加し、合計30件にした。ビジネス、営業、調査、報告、教育、専門職、コンテンツの利用場面をカバーする。
- 各追加テンプレートに、`id`、`title`、`when`、`category`、`source`、`source_url`、`author` のfrontmatterを付与した。本文は `notes` と `transcript` を資料化できる構造にしている。

## 最終試験

以下を t3 の隔離worktree内で実行した。

```sh
scripts/plaud-inbox templates --json
```

- 結果: 30件が列挙され、IDは全て一意。

追加テンプレートのfrontmatterを検査した。

- 結果: 24件すべてに必須7項目がある。

```sh
git diff --check
```

- 結果: 空白エラーなし。
